Compilador Offline de Cartões de Olimpíadas

Gere os arquivos individuais dos alunos localmente no seu computador em um pacote ZIP, livre de erros de limite de memória.

📖 Como funciona?

Este utilitário cruza a planilha Excel de alunos com os arquivos PDFs das olimpíadas para gerar arquivos JSON individuais rápidos de ler.

  • 1. Selecione a planilha Excel dos Alunos contendo as colunas: Nome, CPF e Data Nascimento.
  • 2. Selecione os PDFs das olimpíadas correspondentes (o PDF completo que você recebeu, contendo a página de cada aluno).
  • 3. O compilador lê as páginas, localiza qual aluno pertence àquela folha por cruzamento de Nome/CPF.
  • 4. Ao final, ele baixa um arquivo ZIP chamado `cartoes.zip` contendo os arquivos individuais. Extraia-o como uma pasta chamada `cartoes` na raiz do seu site.
